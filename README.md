# Mila

Η Mila είναι εφαρμογή εξάσκησης προφορικών Αγγλικών με το Gemini. Η συζήτηση γίνεται φωνητικά, ενώ οι φράσεις που λες εμφανίζονται γραπτώς και μπορούν να αναλυθούν για διορθώσεις.

## Τι προσφέρει

- Θέματα συζήτησης και σενάρια εξάσκησης, όπως συνέντευξη, daily stand-up, ταξίδι και ελεύθερη συζήτηση.
- Συνεχή ακρόαση με αυτόματη αναγνώριση παύσεων. Η Mila ξεκινά κάθε συζήτηση με ερώτηση σχετική με το επιλεγμένο θέμα και συνεχίζει να απαντά στις παύσεις σου.
- Αποθήκευση της τελευταίας συζήτησης στη συσκευή και συνέχιση από το ίδιο θέμα και ιστορικό όταν ανοίξεις ξανά την εφαρμογή.
- Προσωρινή παύση και συνέχιση του μικροφώνου από το εικονίδιο μικροφώνου. Το εικονίδιο εξόδου κλείνει τη συνομιλία και επιστρέφει στην επιλογή θέματος.
- Μεταγραφή όσων λες και διορθώσεις σε γραμματική, λεξιλόγιο και φυσική διατύπωση.
- Καρτέλες **Λάθη** και **Λεξιλόγιο**. Κάθε λήμμα λεξιλογίου εμφανίζει την αγγλική λέξη, την ελληνική μετάφραση και παράδειγμα στα Αγγλικά, με δυνατότητα ακρόασης της αγγλικής λέξης.
- Ρυθμίσεις επιπέδου, φωνής, δυσκολίας, γλώσσας επεξηγήσεων, ενδιαφερόντων και ημερήσιου στόχου.

## Απαιτήσεις

- Flutter SDK με Dart SDK `>=3.4.0 <4.0.0`.
- Κλειδί Gemini API από το [Google AI Studio](https://aistudio.google.com/apikey).
- Πρόσβαση στο διαδίκτυο και άδεια χρήσης μικροφώνου.

## Εκκίνηση

```bash
flutter pub get
flutter run
```

Άνοιξε τις **Ρυθμίσεις**, πρόσθεσε το Gemini API key και πάτησε **Αποθήκευση**. Το κλειδί και οι ρυθμίσεις αποθηκεύονται τοπικά στη συσκευή.

## Χρήση

1. Από την καρτέλα **Συνομιλία**, επίλεξε ένα θέμα. Η Mila θα ξεκινήσει με σχετική ερώτηση.
2. Απάντησε όταν θέλεις. Το μικρόφωνο ακούει συνεχώς και η Mila συνεχίζει τη συζήτηση στις παύσεις.
3. Πάτησε το εικονίδιο μικροφώνου για προσωρινή παύση ή για να συνεχίσεις μετά την παύση. Όσο ακούει το μικρόφωνο, το πεδίο πληκτρολόγησης είναι κρυφό.
4. Πάτησε το εικονίδιο εξόδου επάνω δεξιά για να κλείσεις τη συνομιλία και να επιλέξεις άλλο θέμα.
5. Άνοιξε τις καρτέλες **Λάθη** και **Λεξιλόγιο** για να δεις τις διορθώσεις και τις αποθηκευμένες λέξεις.

Μπορείς να πληκτρολογήσεις μήνυμα όταν το μικρόφωνο είναι σε παύση.
Αν κλείσεις την εφαρμογή, επίλεξε **Συνέχισε τελευταία συζήτηση** όταν επιστρέψεις για να ξανασυνδεθείς με το ιστορικό της προηγούμενης συζήτησης.

## Δομή έργου

- `lib/pages/` — οθόνες συνομιλίας, ρυθμίσεων, λαθών και λεξιλογίου.
- `lib/services/` — συνεδρία Gemini Live, κλήσεις Gemini, εγγραφή/αναπαραγωγή ήχου και αποθήκευση.
- `lib/models/` — μοντέλα δεδομένων εφαρμογής.
- `assets/images/` — εικόνες και λογότυπο.
